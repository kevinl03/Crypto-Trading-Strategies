\section{Conclusion}\label{sec:conclusion}

We studied same-asset cross-exchange spread forecasting under live multi-venue microstructure, a setting that still receives little attention relative to single-venue or mechanical pairs rules. Rather than DNN/LSTM architectures common in prior supervised spread work, we use a confidence-gated tree-based baseline: LightGBM forecasts the next z-score, and we trade only when that forecast is large enough. Optimizing the rolling z-score window $w$ and confidence gate $\tau$ yields an hourly Sharpe ratio of 1.90 under the paper protocol. On the live validation campaign, LightGBM at $|\hat{z}| \geq 0.9$ reaches directional accuracy of 86.7\% and R$^2$ of 0.599 on settled closes ($n{=}12{,}795$), improving per-trade win rate by 15.4~percentage points versus capacity-matched mechanical z-score persistence. The confidence filter lifts R$^2$ by selecting high-signal environments; on those rows, much of the value is in capturing spread magnitude, not only direction. Engineered lag and momentum features explain a large share of predictive power, with a smaller but useful contribution from real-time microstructure collected through exchange APIs.

On the same out-of-sample test set used for LightGBM, a classical Random Forest baseline agrees closely on ranking ($\mathrm{corr}\approx 0.98$). That shows the signal is not unique to gradient boosting. We still report LightGBM because it has higher R$^2$ and about twice as many trades at the absolute $|\hat{z}|\geq 0.9$ gate. Taken together, the results support a simple but effective tree baseline for this problem setting, not a claim that one particular learner is uniquely required. The released code and data are meant so others can improve on this baseline.

\subsection{Future Work}

Incorporating more realistic fee structures would bridge the gap between z-unit performance and economic profitability. The released dataset lets the community benchmark alternative models, including deeper sequence models and stronger tabular peers, on the same cross-exchange microstructure data.
